# Тренировки — веб-приложение для iPhone (PWA)

Бесплатная версия без Xcode, аккаунта и серверной базы данных. **Все пользовательские записи хранятся в локальном хранилище браузера на данном устройстве**. После установки на главный экран данные не синхронизируются с другими устройствами.

## Что работает

- Несколько профилей. Для каждого: имя, тренер, вид занятий, дни недели, целевой вес тела, настройка проверки пропусков.
- Абонементы: дата оплаты, сумма в ₽, количество занятий, отдельная дата начала, комментарий.
- Автоматический график по указанным дням. При новой оплате график продолжится после уже запланированных занятий.
- При открытии приложения вопросы о прошлых неподтверждённых тренировках. «Да» списывает занятие, «Нет» не списывает и добавляет заменяющую дату. Можно отвечать позже.
- Перенос даты запланированной тренировки.
- Дневник: готовая библиотека упражнений, собственные упражнения, дата, произвольное количество подходов с **разными** повторениями и весами, заметки, редактирование и удаление.
- Аналитика: общие расходы, расходы за текущий месяц, средняя цена оплаченного занятия, стоимость уже использованных занятий, гистограмма по месяцам. Оплаты без суммы исключаются из денежных итогов.
- Контроль веса: измерения по датам, график, цель, редактирование.
- Экспорт данных в JSON и импорт из резервной копии.
- Офлайн-работа после первого открытия размещённого сайта, когда Service Worker успел закешировать файлы.

## Как бесплатно разместить на Cloudflare Pages

1. Зарегистрируйтесь / войдите в https://dash.cloudflare.com/.
2. Откройте **Workers & Pages** → **Create application** → **Pages** → **Upload assets** (названия пунктов могут отличаться).
3. Укажите любое свободное имя проекта, например `moi-trenirovki`.
4. Загрузите ZIP-архив, в котором `index.html` лежит **в корне**, либо перетащите папку `Trenirovki_PWA`.
5. Нажмите **Deploy**. Получите адрес вида `https://moi-trenirovki.pages.dev` (если это имя свободно).

Это бесплатный поддомен Cloudflare — покупка своего домена не нужна. Сам сайт (программные файлы) публикуется в интернете, но **ваши записи с оплатами, упражнениями и весом не выгружаются** на хостинг и остаются локальными.

## Как установить на iPhone

1. Откройте полученную ссылку в Safari на iPhone.
2. «Поделиться» → «На экран Домой» → включите «Открывать как веб-приложение» (если есть) → «Добавить».
3. **Вносите записи уже в установленном приложении** (а не во вкладке Safari), чтобы работать в одном локальном хранилище.
4. Проверьте работу без интернета после того, как приложение хотя бы раз полностью открылось с интернетом.

## Важно о данных

- Рекомендуется **после значимых изменений**: Настройки → «Скачать резервную копию» и сохранить JSON в «Файлы»/на другой носитель. При желании можно сохранять резервную копию в iCloud Drive — это будет **ручной экспорт**, не автоматическая синхронизация приложения.
- При удалении веб-приложения, очистке Safari/системного хранилища, сбросе устройства данные **могут пропасть**.
- Данные прежней нативной Xcode-версии **не переносятся автоматически**, если она уже была установлена. Нужен отдельный совместимый механизм экспорта из нативной версии.
- Уведомлений в фоне нет: проверка пропущенных занятий идёт **только при открытии** приложения.
- Для первого открытия нужен Интернет и HTTPS. Для локального теста разработчиком можно поднять статический сервер, например `python3 -m http.server 8000` и открыть его на компьютере. Для установки на iPhone нужен опубликованный HTTPS URL.
- Реальное выполнение на iPhone не проверялось в данном окружении; протестированы JavaScript-синтаксис и расчёт расписания, балансов, цен и разделения участников.

## Файлы

- `index.html` — приложение.
- `styles.css` — стили для iPhone.
- `app.js` — вся логика и локальное хранение.
- `manifest.webmanifest` — настройки установки.
- `sw.js` — кеширование файлов для офлайн-режима.
- `icons/` — иконки.
